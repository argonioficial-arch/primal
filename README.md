# 🦍 PRIMAL
### INVESTIGATE. PROTECT. DOMINATE.

**PRIMAL** is an independent organization dedicated to digital investigations, cybersecurity, threat analysis and server protection.

Our mission is to identify threats, investigate suspicious activity, strengthen digital communities and promote a safer online environment.

We believe in discipline, teamwork, confidentiality and responsible investigations.
